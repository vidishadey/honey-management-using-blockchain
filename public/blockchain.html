🧪 Controlled Viva Tampering Demonstration Studio

Examiner Interactive Mode

How it works: In a regular database without a blockchain layer, an attacker or compromised admin can silently edit records (e.g. change a Failed pesticide test to Passed). In our system, modifying any block's data invalidates its SHA-256 signature and breaks the chain. Use this interactive tool to demonstrate this to the examiner.

Tip: Select a block and click Simulate Malicious Tamper, then inspect the red alert below!
ℹ
Academic Architecture Note: This application demonstrates a local cryptographic hash-linked ledger. While data tampering is instantly detected through SHA-256 linkages, a production-grade decentralized blockchain utilizes distributed Byzantine Fault Tolerant (BFT) consensus algorithms across multiple independent nodes. In our single-node prototype, the ledger is persistently maintained in MongoDB.
